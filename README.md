# Data Analysis Practice Data

데이터 분석 수업과 실습에 사용하는 예제 데이터 파일을 정리한 저장소입니다.

## 데이터 형식
- CSV
- Excel (XLS/XLSX)
- JSON 및 기타 예제 파일

## 활용
Pandas 등을 이용한 데이터 불러오기, 정제, 탐색적 데이터 분석, 표와 시각화 실습에 활용할 수 있습니다.

## 참고
파일별 출처와 컬럼 정의는 원본 데이터 및 수업 노트를 확인해 주세요. 특히 선거·인구·범죄·위치 관련 데이터는 해석 시 기준 시점과 출처를 확인하고, 재배포 가능 여부를 검토하세요.
